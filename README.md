# Image Quality

Research image-quality tool for prototype bead captures and archival organoid images.

Open index.html, or enable GitHub Pages from main / (root).

Includes a 48-image bead review sample from 606 measured captures, 38 archival organoid examples, 20 paired comparisons, browser-local illumination trials and a saved-image controller replay. New trials are local to the visitor browser, not shared server uploads. Live recaptures and storage integration remain pending.

Source, tests, measurements, integration notes and assistance documentation are included in Mariam_Meeting_Package.zip. The source package retains source attribution and AI_USE.md.
